# 巷口選物（Lane Mart）

VIT2621 Vibe Coding & Web Authoring 小型專題研習 — 購物網站示範。

## 技術

- 純 **HTML5 / CSS3 / JavaScript**（無 TypeScript、無前端框架）
- **RWD**：適配電腦、平板、手機
- 購物車資料使用瀏覽器 `localStorage`

## 頁面

| 檔案 | 說明 |
|------|------|
| `index.html` | 首頁 |
| `products.html` | 商品一覽、選貨、數量、計算小計 |
| `about.html` | 關於我們、服務時間表格 |
| `contact.html` | 聯絡／查詢表單 |
| `cart.html` | 購物車、運費與總額結算 |

## 本機預覽

用瀏覽器直接開啟 `index.html`，或在專案根目錄執行：

```bash
python3 -m http.server 8080
```

然後開啟 `http://127.0.0.1:8080/`。

## 評分對應（網站部分）

1. 至少 4 頁網頁（本站 5 頁）
2. 表格與文字（價目表、服務時間、運費表）
3. 相片／圖檔（`images/` 內 SVG 示意圖，附圖說）
4. 可於瀏覽器順利顯示
5. 外部 CSS（`css/style.css`）訂立文字與版面外觀
6. 格式化文字（粗體、斜體、清單等）
7. 合宜佈局（頁首／導覽／內容／頁尾）
8. RWD（媒體查詢）
9. JavaScript：用戶輸入、選擇貨物、數量
10. JavaScript：計算總額並給予回應
11. 內容與互動完整，並以 AI 協作產生後再人手調整
